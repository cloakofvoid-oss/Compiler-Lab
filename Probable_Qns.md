# Yacc and Lex Questions which are for exam to study

## SET1
1.Implement a YACC program to evaluate expression a n b n /n≥1

2. Write a program to find First and Follow of any given grammar.
S → A | B
A → a S | b
B → b S | c

3.Implement a YACC calculator program with precedence

4.Implement a YACC program to evaluate an arithmetic expression

5.Lex program to count the no of comment line in a given C program. Also
eliminate them and copy that program into separate file.

6. Program to recognize strings ‘xxxy’, ‘xyyy’, ‘xy’ and ‘x’ using grammar
L=(x^n y^n , n&gt;=0).

7 a) Implement a lex program to check a Pincode is valid or not.
b).Implement a Lex program to extract HTML tags from a html program.

8. a).Write a Lex program for checking a valid e-mail ID. Read the data from a
file.
b).Implement a lex program to check a date is valid or not?

9) Implement Intermediate code generation for simple expressions.
a) ( a + b ) * ( c + d )
b) 2 + 3 * 5 + 7

10) Design and implement a lexical analyzer using C language to recognize all
valid tokens in the input program. The lexical analyzer should ignore
redundant spaces, tabs and newlines. It should also ignore comments.

11) Write a program to convert NFA with ε transition to NFA without ε
transition.
